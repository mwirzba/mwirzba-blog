Cześć, jestem Mateusz

Senior software developer z ponad 6-letnim doświadczeniem w tworzeniu wydajnych i skalowalnych aplikacji.

Specjalizacja#

Specjalizuję się przede wszystkim w backendzie i ekosystemie C#/.NET. Buduję aplikacje oparte na mikroserwisach oraz architektury mikro-modularne, korzystając z podejść Domain-Driven Design, CQRS i Modular Monolith. Codziennie pracuję nad utrzymywalnym kodem, wydajnością i niezawodnością systemów opartych na Entity Framework oraz innych rozwiązaniach dostępu do danych.

Mam również doświadczenie we frontendzie — React, Angular, JavaScript i TypeScript. Pozwala mi to dobrze rozumieć przepływ danych i integracje pomiędzy warstwą użytkownika a usługami backendowymi.

Technologie i obszary#

  • C#, .NET, Entity Framework i Dapper
  • Microservices, DDD, CQRS i Modular Monolith
  • Apache Kafka, RabbitMQ i Azure Service Bus
  • PostgreSQL, Microsoft SQL Server i Oracle
  • NUnit, xUnit, Moq i Pact
  • Microsoft Azure, Docker i CI/CD
  • Azure DevOps, Git, JIRA, Confluence i praktyki Agile/Scrum
